================================================================================
          VIT (STUDY AI ASSISTANT) - SETUP, SECURITY & WORKFLOW GUIDE
================================================================================

This document provides a comprehensive overview of how the VIT Study AI Assistant 
works, step-by-step instructions for Windows and Linux/Mac, and detailed security 
clarifications so users know their systems are completely safe.

--------------------------------------------------------------------------------
1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
VIT is a lightweight, keyboard-driven study assistant designed to run on top of 
your browser or windows. It captures questions or screen selections, captures system/mic 
audio, sends chunks securely to Google Gemini API for fast transcription and analysis, 
and displays assistance in a sleek user interface.

It consists of:
- A Frontend/Desktop Window: Built using Electron (Chromium + Node.js).
- A Backend Server: Runs locally on your machine on port 3000 to manage secure APIs.

--------------------------------------------------------------------------------
2. STEP-BY-STEP SECURITY & DATA FLOW AUDIT (Why it is 100% safe)
--------------------------------------------------------------------------------
Here is the exact lifecycle of the application, broken down step-by-step from a 
security and data privacy perspective:

STEP 1: SCRIPT INGESTION (In-Memory Only)
- Action: When you paste the one-liner command (`curl ... | bash` or `irm ... | iex`), 
  the script content is downloaded directly into your shell's RAM. 
- Security: No physical `.sh` or `.ps1` installer file is ever written to your persistent 
  hard drive. This prevents antivirus flagging associated with saved unverified scripts.

STEP 2: DIRECTORY CREATION & DOWNLOAD (User Space Only)
- Action: The script creates a temporary folder in your standard User Space:
  * Windows: `%LOCALAPPDATA%\vit` (e.g., C:\Users\<Username>\AppData\Local\vit)
  * Linux/Mac: `/tmp/vit-app-XXXXXX`
- Security: Because it operates entirely within the current user's profile, it does NOT 
  require Administrator or Root privileges. It cannot modify system-protected directories 
  (like C:\Windows or /usr/bin).

STEP 3: FILE EXTRACTION & AUDIT
- Action: The script downloads and extracts the application zip. The extracted files 
  consist of:
  * Electron runtime binaries (standard Chromium browser & Node.js).
  * HTML, CSS, and Javascript source files.
- Security: The app contains ZERO kernel-level drivers, hook engines, or persistent 
  system services. It runs as a standard, unprivileged web browser process.

STEP 4: NETWORK & LOCALPORT ACTIVITY
- Action: The backend starts a local server on port 3000 (`localhost:3000`).
- Security: This server is bound *exclusively* to `localhost` (127.0.0.1). It is completely 
  inaccessible to the outside network or other devices on your Wi-Fi. 

STEP 5: SCREEN & AUDIO CAPTURE PRIVACY
- Action: When taking screenshots or using the audio listener:
  * Screenshots are captured locally using Chromium's native screen capture API.
  * Audio is recorded using standard WebRTC media streams.
- Security: Captured image and audio data are processed purely in memory. They are 
  NEVER written to disk, stored in databases, or logged.
- Transmission: Audio chunks and screenshot data are sent securely via TLS 1.2/1.3 
  encrypted HTTPS connections directly to Google's official Gemini API endpoints. 
  No third-party proxy or intermediary servers are involved.

STEP 6: COMPLETE PROCESS & FILE CLEANUP ON EXIT (TOTAL SELF-DESTRUCT)
- Action: When you trigger a quit (via Ctrl+Shift+Q, Alt+Shift+Q, or closing the window):
  * All Node.js backend processes and Electron browser processes are forcefully terminated.
  * In-memory RAM keys, tokens, and clipboard traces are zeroed out immediately.
  * PowerShell terminal command history is wiped clean.
  * Self-Destruct Wipe: Automatically deletes the entire %LOCALAPPDATA%\vit installation 
    folder and all temporary files from the system so zero files remain on disk.
- Security: No persistent background daemons, spyware, files, or registry keys 
  remain on your computer. When it closes, it leaves zero digital footprints.

3. WINDOWS SETUP FLOW & WORKFLOW (No File Explorer Required)
--------------------------------------------------------------------------------
Command to paste in PowerShell:
irm https://raw.githubusercontent.com/sandeep2421-hub/study-ai-assistant/main/setup.ps1 | iex

* Note: You do NOT need access to a File Manager or Explorer to run or install this app.

STEP-BY-STEP WORKFLOW (Windows):
1. RUNNING THE COMMAND:
   PowerShell fetches the `setup.ps1` script directly into RAM/memory and starts 
   executing it. It does not download any installer file to your downloads folder.
   
2. THE DOWNLOAD & STORAGE STAGE:
   The script extracts the app to your temporary user space:
   Path: %LOCALAPPDATA%\vit (which is C:\Users\<Username>\AppData\Local\vit)
   It downloads the portable app archive (~80MB ZIP file containing precompiled 
   Chromium/Electron and Node binaries) directly to this folder and extracts it.

3. PREVENTING EXTRACTION CONFLICTS:
   Before extracting, the script automatically sweeps and cleans any old conflicting files 
   in %LOCALAPPDATA%\vit to ensure a fresh, error-free launch.

4. SETTING UP LAUNCH SHORTCUTS (No folder browsing needed):
   The script adds a quick shortcut function named `vit` to your PowerShell profile. 
   In the future, you never need to look for files or browse folders. Just open 
   PowerShell, type `vit`, and press Enter to launch the app instantly!

5. LAUNCHING THE APP:
   The script launches the executable and starts running.

--------------------------------------------------------------------------------
4. LINUX & MAC SETUP FLOW & WORKFLOW (In-Memory Only)
--------------------------------------------------------------------------------
Command to paste in Terminal (Linux/Mac):
curl -sL https://raw.githubusercontent.com/sandeep2421-hub/study-ai-assistant/main/setup.sh | bash
(or: wget -qO- https://raw.githubusercontent.com/sandeep2421-hub/study-ai-assistant/main/setup.sh | bash)

* Note: No file manager access is required. The app is fetched and run purely via Terminal.

STEP-BY-STEP WORKFLOW (Linux/Mac):
1. RUNNING THE COMMAND:
   The terminal downloads the shell script `setup.sh` directly into memory and 
   passes it to `bash` for execution.

2. AUTO-INSTALL PREREQUISITES (Node.js):
   The script checks if Node.js is installed. If Node.js is missing, the script 
   automatically detects your operating system package manager and installs it:
   - Ubuntu/Debian: apt-get
   - CentOS/RHEL/Fedora: yum/dnf
   - Arch Linux: pacman
   - Alpine Linux: apk
   - macOS: Homebrew (installs Homebrew if missing)

3. THE DOWNLOAD & STORAGE STAGE:
   The script creates a temporary, hidden directory under:
   Path: /tmp/vit-app-XXXXXX (where XXXXXX is a random session ID).
   It clones the repository into this temporary folder.

4. LOCAL RUN STAGE:
   It runs `npm install` inside the temporary folder to download dependencies, 
   starts the local server, and launches the Electron application.

5. HOW TO QUIT & CLEANUP (100% trace-free):
   The script utilizes a bash `trap` command. The second you close the app window 
   or hit Ctrl+C in the terminal:
   - The backend server is killed immediately.
   - The temporary directory /tmp/vit-app-XXXXXX and all its contents are 
     deleted permanently (rm -rf).
   - The system is left in the exact same state as before running.

5. KEY SHORTCUTS QUICK-REFERENCE
================================================================================
Once the application window launches, use these global keys:
* Main Controls:
  - Ctrl+Shift+S          : Capture screenshot silently
  - Ctrl+Shift+A          : Ask / generate answer
  - Ctrl+Shift+L          : Toggle audio listener (voice recognition)
  - Ctrl+Shift+C          : Copy text from external window into app
  - Ctrl+Shift+V          : Auto-type last code snippet at OS cursor
  - Ctrl+Shift+K          : Toggle kiosk / stealth mode (low opacity, unfocusable)
  - Ctrl+Shift+H          : Hide / show window (or use Alt+Shift+H)
  - Ctrl+Shift+Q          : Quit app (or use Alt+Shift+Q)

* Navigation & Editing:
  - Ctrl+Shift+R or E     : Reset / clear all / abort current request
  - Ctrl+Shift+P          : Pause / resume scroll
  - Ctrl+Shift+Up/Down    : Scroll answer text up/down
  - Ctrl+Shift+X          : Cycle code languages
  - Alt+Shift+Up/Down/L/R : Move overlay window position
  - Alt+Shift+F1/F2       : Opacity up/down
  - Triple-tap Alt+Shift+Backspace: Panic kill and wipe processes
